# 07-05 CPI、SPI、EAC、ETC、VAC 与成本控制

## 1. 专题定位
本专题解决“CPI、SPI、EAC、ETC、VAC 与成本控制”在系统集成项目管理工程师考试中的识别、辨析和应用问题。它所属知识域为 **项目成本管理**，主要用途是：计算卡 / 案例卡。学习目标不是背一个孤立名词，而是能在题干或案例背景中判断对象、阶段、角色、输出和错误说法。

## 2. 核心概念与边界
| 层次 | 要点 | 学习抓手 |
|---|---|---|
| 1 | CPI 等于 EV 除以 AC，小于1成本超支 | 追问“对象、条件、输出、角色、例外”。 |
| 2 | SPI 等于 EV 除以 PV，小于1进度落后 | 追问“对象、条件、输出、角色、例外”。 |
| 3 | EAC 是完工估算，ETC 是完工尚需估算，VAC 等于 BAC 减 EAC | 追问“对象、条件、输出、角色、例外”。 |
| 4 | 非典型偏差 ETC 等于 BAC 减 EV，典型偏差 ETC 等于 BAC 减 EV 后除以 CPI | 追问“对象、条件、输出、角色、例外”。 |
| 5 | 成本控制包括监控偏差、预测完工、控制未经批准变更和通知干系人 | 追问“对象、条件、输出、角色、例外”。 |

边界提醒：本专题只处理与“CPI、SPI、EAC、ETC、VAC 与成本控制”直接相关的概念、流程、计算或案例证据；当它与相邻专题交叉时，优先用题干中的**对象**、**过程阶段**、**责任角色**和**输出物**定位。

## 3. 知识结构
- CPI 等于 EV 除以 AC，小于1成本超支
- SPI 等于 EV 除以 PV，小于1进度落后
- EAC 是完工估算，ETC 是完工尚需估算，VAC 等于 BAC 减 EAC
- 非典型偏差 ETC 等于 BAC 减 EV，典型偏差 ETC 等于 BAC 减 EV 后除以 CPI
- 成本控制包括监控偏差、预测完工、控制未经批准变更和通知干系人

建议把本专题整理成“定义、适用条件、典型输出、错误说法、真题关键词”五列。软考题经常不是直接问定义，而是把一个正确概念换到错误场景里，或者把相邻过程的输出物调换。

## 4. 关键流程 / 方法 / 公式
- 先判断偏差是否持续再选公式
- 数值判断后要翻译成管理语言

若本专题含公式，制卡时必须同时记变量含义、代入顺序和结果解释；若本专题含流程，优先拆成“谁提出、谁评估、谁批准、更新什么文件、如何验证”的小卡。

## 5. 易混点与辨析
- CPI=0.91 不是投资91创造100
- EAC 看总完工，ETC 看还需

辨析题不要靠关键词联想直接选答案，要先确认题干问的是“管理办法、工作成果、检查活动、正式验收、风险预判、已发生问题”中的哪一类。

## 6. 真题考法
- 历年题给 BAC、EV、AC 要求 ETC/EAC
- 案例问成本控制主要工作

常见命题方式包括：定义识别、过程归属、输入输出、角色权限、公式变量、案例证据归因和错误选项排除。遇到含糊表述时，优先回到教程过程定义和已批准文件。

## 7. 典型例题或题型拆解
若 CPI<1 且 SPI<1，应判断成本超支、进度落后并提出纠偏

拆题步骤：先圈角色和阶段，再圈文件或数字，最后判断是否存在越权、漏评审、未确认、未走变更、公式口径错误或把相邻概念调换的问题。

## 8. 制卡建议
- 计算卡：题干变量、公式、代入、结果解释各拆一张。
- 案例卡：用一条背景证据反问对应管理问题、原因和措施。
- 错因卡：把真题错项改写成“为什么这句话不成立”。

Anki 卡片应保留最小上下文，例如“范围基准已批准后”“客户正式签字时”“题干给出 PV/EV/AC 时”。这样复习时训练的是迁移判断，而不是孤立背词。
