# 16-05 计算题审题与防错模板

## 1. 专题定位
本专题解决“计算题审题与防错模板”在系统集成项目管理工程师考试中的识别、辨析和应用问题。它所属知识域为 **计算题专题**，主要用途是：方法卡 / 易错卡。学习目标不是背一个孤立名词，而是能在题干或案例背景中判断对象、阶段、角色、输出和错误说法。

## 2. 核心概念与边界
| 层次 | 要点 | 学习抓手 |
|---|---|---|
| 1 | 先圈问题要求：求数值、判断状态、写措施还是解释原因 | 追问“对象、条件、输出、角色、例外”。 |
| 2 | 列变量表，不直接心算 | 追问“对象、条件、输出、角色、例外”。 |
| 3 | 统一单位：天、周、月、元、万元、百分比和小数 | 追问“对象、条件、输出、角色、例外”。 |
| 4 | 写公式、代入、结果、管理判断四步 | 追问“对象、条件、输出、角色、例外”。 |
| 5 | 检查正负号、大于小于1、是否含管理储备、日期边界 | 追问“对象、条件、输出、角色、例外”。 |

边界提醒：本专题只处理与“计算题审题与防错模板”直接相关的概念、流程、计算或案例证据；当它与相邻专题交叉时，优先用题干中的**对象**、**过程阶段**、**责任角色**和**输出物**定位。

## 3. 知识结构
- 先圈问题要求：求数值、判断状态、写措施还是解释原因
- 列变量表，不直接心算
- 统一单位：天、周、月、元、万元、百分比和小数
- 写公式、代入、结果、管理判断四步
- 检查正负号、大于小于1、是否含管理储备、日期边界

建议把本专题整理成“定义、适用条件、典型输出、错误说法、真题关键词”五列。软考题经常不是直接问定义，而是把一个正确概念换到错误场景里，或者把相邻过程的输出物调换。

## 4. 关键流程 / 方法 / 公式
- 案例计算即使算错，公式和过程也能拿部分分
- 计算后必须翻译成管理语言

若本专题含公式，制卡时必须同时记变量含义、代入顺序和结果解释；若本专题含流程，优先拆成“谁提出、谁评估、谁批准、更新什么文件、如何验证”的小卡。

## 5. 易混点与辨析
- CV/SV 正负不要反
- 第 n 月末和第 n 个月内不要混
- EV 不是 AC

辨析题不要靠关键词联想直接选答案，要先确认题干问的是“管理办法、工作成果、检查活动、正式验收、风险预判、已发生问题”中的哪一类。

## 6. 真题考法
- 下午题评分重步骤，空白最亏

常见命题方式包括：定义识别、过程归属、输入输出、角色权限、公式变量、案例证据归因和错误选项排除。遇到含糊表述时，优先回到教程过程定义和已批准文件。

## 7. 典型例题或题型拆解
写 CPI=0.763、SPI=0.774，所以成本超支、进度落后，比只写两个数更稳

拆题步骤：先圈角色和阶段，再圈文件或数字，最后判断是否存在越权、漏评审、未确认、未走变更、公式口径错误或把相邻概念调换的问题。

## 8. 制卡建议
- 定义/判断卡：只考一个概念边界或一个错误说法。
- 对比卡：围绕对象、阶段、输出、角色和常见错项做双面对照。
- 错因卡：把真题错项改写成“为什么这句话不成立”。

Anki 卡片应保留最小上下文，例如“范围基准已批准后”“客户正式签字时”“题干给出 PV/EV/AC 时”。这样复习时训练的是迁移判断，而不是孤立背词。
