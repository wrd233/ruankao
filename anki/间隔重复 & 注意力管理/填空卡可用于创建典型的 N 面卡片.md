# 填空卡可用于创建典型的 N 面卡片

> [原文链接](https://zhuanlan.zhihu.com/p/615872471)

典型的[间隔重复记忆系统](https://link.zhihu.com/?target=https%3A//notes.andymatuschak.org/z4eXdSMJFv2qVGXSUEKH4vdcHBrLHcFY1ZGfC)[1]会将填空卡和问答卡用不同的方式展示，但有趣的是，你可以将典型抽认卡（问答卡）视为填空卡的特例。

也就是说，可以用填空卡来构造问答卡，把回答的内容挖空即可。

我正在本人的实践中利用这种观察，见[我的个人助记媒介实现](https://link.zhihu.com/?target=https%3A//notes.andymatuschak.org/z4mAF1uBV96r72e4NjLcDaujEyTPGiUQJEj8C)[2]； [Log：个人助记媒介](https://link.zhihu.com/?target=https%3A//notes.andymatuschak.org/zzqNiAYNTSENmBcCV4zkNBrVKWoqXqFmNFL) 。例子如下图：
