## 导入方法

如果使用 `cards.tsv` 导入 Anki，请选择 UTF-8 编码、字段分隔符为 Tab，并按表头映射字段。若 `deck.apkg` 存在，可直接双击或通过 Anki 的“文件 → 导入”导入。
