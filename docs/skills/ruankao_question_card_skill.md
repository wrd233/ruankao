# 软考真题刷题卡 Skill

真题卡用于训练考试反应，不能改写成普通概念卡。卡片必须保留题干、选项、答案、解析边界和来源定位。

## 上午选择题

Front 必须包含年份或来源定位、题号、题干和 A/B/C/D 选项。Back 只放答案。Extra 放为什么选、错项分析、题干信号、关联专题和可迁移考点。

## 下午案例题

下午案例不宜做成一张巨型卡。应拆成场景识别卡、原因分析卡、措施框架卡、计算题卡和案例陷阱卡，并保留来源题号或案例定位。

## 解析边界

如果题干、选项、答案、解析无法稳定对应同一道题，不编造解析，不借用相邻题解析，不进入 keep，写入 `question_parse_needs_review.md`。

## 审稿

真题卡质量由人工阅读判断，不用代码质量评分，不输出 `quality_score`。
