# 软考计算卡 Skill

计算专题不能只做公式卡，必须形成“公式理解 → 变量辨析 → 判断规则 → 极简计算 → 综合计算 → 陷阱 → 案例表达”的复习链。

## 适用专题

- 挣值管理 EVM
- 关键路径、总时差、自由时差
- PERT 三点估算
- 沟通渠道数
- EMV 与决策树
- 投资评价、回收期、净现值等需要教材口径确认的经济评价

## 卡型

- 公式卡：公式、变量含义、判断规则。
- 变量辨析卡：解释容易混的变量。
- 计算卡：给数据、分步算、写文字判断。
- 陷阱卡：说明信息不足、符号错用、量纲混淆。
- 案例表达卡：把计算结果翻译成下午案例得分句。

## 禁止

不得只写公式不写含义，不得只写答案不写判断，不得一张卡塞多个无关公式，不得用脚本给卡片打分。
