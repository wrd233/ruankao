# 02_极细粒度专题知识树_叶节点为专题

## 图例

- `◇`：知识域 / 专题组，不直接生成专题文件。
- `◆`：叶节点专题，后续必须生成学习包。
- **重要度**：A 高频核心；B 常考支撑；C 辅助理解；D 低频了解。
- **题型**：选择 / 案例 / 计算 / 辨析 / 记忆 / 方法论。
