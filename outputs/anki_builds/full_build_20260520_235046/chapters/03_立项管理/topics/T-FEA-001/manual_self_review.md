# T-FEA-001 人工自评

- keep｜项目建议书在立项管理中的核心作用是什么？：Front 明确问作用，Back 短，Extra 只补阶段边界。
- keep｜项目建议书 vs 项目章程的核心区别是什么？：跨专题边界清楚，和作用卡不是同义重复。
- keep｜项目建议书获批后，通常进入哪类工作？：只考相邻流程关系，适合选择题。
- keep｜项目建议书阶段为什么也可能组织需求分析？：解释立项前需求分析的特殊位置。
- keep｜可行性研究在立项管理中解决什么问题？：中心概念卡，Back 稳定且短。
- keep｜教程口径下，可行性研究通常要覆盖哪七类内容？：小型枚举但为教程明确考点，Extra 分组减负。
- keep｜题干出现哪些信号时，应优先想到技术可行性？：把抽象分类落到案例信号上。
- keep｜财务可行性 vs 经济可行性的区别是什么？：拆开两个字面相似概念。
- keep｜题干出现哪些信号时，应想到组织可行性？：补足案例中常被忽略的非技术原因。
- keep｜题干出现哪些信号时，应想到社会可行性？：专注社会可行性，和技术可行性互补。
- keep｜可行性研究是否只需要论证收益，不需要论证风险？：纠正高频误解，Back 简短。
- keep｜可行性研究是不是项目管理计划？：短、准、有坑点，接近黄金样例风格。
- keep｜可研报告内容相对项目建议书批复发生重大变更时，应优先想到什么处理？：不写具体数字，保留稳定判断规则。
- keep｜机会研究主要回答什么问题？：Front 和 Back 都很短。
- keep｜初步可行性研究主要回答什么问题？：聚焦“是否深入”。
- keep｜详细可行性研究主要回答什么问题？：Back 稳定，Extra 只补定位信号。
- keep｜机会研究、初步可研、详细可研的核心区别是什么？：必要总辨析卡，和单概念卡构成合理冗余。
- keep｜初步可行性研究通常可能得出哪四类结论？：四项枚举是稳定考点，未扩成长段。
- keep｜可研报告从编制到批复的大致链路是什么？：流程短，能直接用于立项链条题。
- keep｜项目评估在立项管理中的核心作用是什么？：贴合教程关键词，Extra 给出做题信号。
- keep｜项目论证 vs 项目评估的核心区别是什么？：本专题关键辨析，专题包和索引支持。
- keep｜多方案择优和项目取舍时，为什么项目评估报告比可研报告更像决策依据？：来自真题解析，修正具体错选。
- keep｜题干出现哪些信号时，应优先想到“可行性研究”？：直接服务做题定位。
- keep｜题干出现哪些信号时，应优先想到“项目评估”？：与定义卡互补，不重复。
- keep｜立项不足类案例通常从哪些角度分析问题？：下午题框架卡，不是教程摘抄。
- keep｜案例题问“进行项目可行性研究的主要步骤”时，可以按什么顺序答？：题目原答案边界稳定，适合作为案例流程卡。
- needs_human_review｜项目建议书“核心内容”题中，风险因素及对策是否一定属于核心内容？：揭示材料冲突，但不作为确定知识强背。
- needs_human_review｜三级可研常见误差范围如何对应？：方向稳定，数字暂不进主复习。
- needs_human_review｜初步设计和投资概算相对可研批复发生重大变更或超出一定额度时，是否要重新报批可研报告？：规则方向可用，数字需要人工确认。
