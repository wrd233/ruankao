# T-SCH-003 formula_cards.md

## 总时差的计算公式有哪两种等价形式？如何判断？

Back：总时差（TF）= LS − ES = LF − EF。TF > 0 表示活动有浮动时间；TF = 0 表示活动无浮动（是关键活动候选）；TF < 0 表示进度已落后于计划。

Extra：<div>理解：两种公式等价，计算结果相同。常见错法：把 ES 当被减数。记住口诀：最迟减最早，开始对开始、完成对完成。</div><div>来源：T-SCH-003</div>

Manual review：keep。总时差双公式是网络图计算的基础，需熟练掌握两种等价形式。

## 自由时差的计算公式是什么？它与总时差的核心区别在哪？

Back：自由时差（FF）= min(所有紧后活动的 ES) − 本活动的 EF。核心区别：总时差看的是"不影响项目总工期"，自由时差看的是"不影响紧后活动的最早开始"。

Extra：<div>理解：常见错法：忘了取"最小值"，错取最大值或平均值。关键技巧：紧后 ES 靠正推法得到，取其中最小的那个。自由时差 ≤ 总时差恒成立。</div><div>来源：T-SCH-003</div>

Manual review：keep。自由时差公式中"取最小值"是高频易错点，需反复练习。

## 正推法（Forward Pass）计算 ES 和 EF 的规则是什么？

Back：规则：① 起始活动 ES = 0（或指定日期）；② EF = ES + 工期；③ 后续活动的 ES = 所有紧前活动中最大的 EF。口诀：顺箭线，取最大。

Extra：<div>理解：常见错法：汇合点处取了"平均"或"最小"。正确理解：只有所有紧前都完成后续才能开始，所以取最大的 EF。</div><div>来源：T-SCH-003</div>

Manual review：keep。正推法"取最大"是网络图计算的第一个关键操作，规则必须记牢。

## 逆推法（Backward Pass）计算 LS 和 LF 的规则是什么？

Back：规则：① 结束活动 LF = 项目总工期（正推结果的最后 EF）；② LS = LF − 工期；③ 前置活动的 LF = 所有紧后活动中最小的 LS。口诀：逆箭线，取最小。

Extra：<div>理解：常见错法：逆推时忘了取最小，取了最大。正推取最大，逆推取最小，两个方向要分清。口诀对照记忆：顺大逆小。</div><div>来源：T-SCH-003</div>

Manual review：keep。逆推法与正推法互为逆运算，是网络图计算的核心方法。

## 如何判断一个活动是否在关键路径上？

Back：核心条件：总时差 TF = 0（即 LS = ES 且 LF = EF）。注意：当项目有多条关键路径时，所有关键路径上的活动 TF 都为 0；当项目规定了强制完工日期时，关键路径上的活动 TF 为最小负值。

Extra：<div>理解：常见错法：认为"所有 TF=0 的活动都在同一路径上"。实际上多条关键路径时，不同路径上的活动 TF 都可能为 0。关键路径的本质定义是"最长的路径"，TF=0 是单关键路径情况下的推论。</div><div>来源：T-SCH-003</div>

Manual review：keep。关键路径判断条件是网络图计算的核心结论，需结合多条关键路径场景理解。
