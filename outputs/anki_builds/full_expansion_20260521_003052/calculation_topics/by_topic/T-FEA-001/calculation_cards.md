## 某项目各年净现金流：第0年=-1000万，第1年=300万，第2年=400万，第3年=500万，第4年=600万，折现率10%。计算NPV并判断是否可行。

Back：NPV = -1000 + 300/(1.1)^1 + 400/(1.1)^2 + 500/(1.1)^3 + 600/(1.1)^4 = -1000 + 272.73 + 330.58 + 375.66 + 409.81 = 388.78万元。NPV > 0，项目可行。

Extra：<div>理解：常见错法：忘记第0年现金流为负时不需要折现，或折现指数写错。第t年折现因子 = (1+i)^(-t)。</div><div>来源：T-FEA-001 经济评价专题</div>

## 某项目各年净现金流：第0年=-800万，第1年=-200万，第2年=300万，第3年=400万，第4年=500万，第5年=500万，折现率12%。计算NPV并判断是否可行。

Back：NPV = -800 + (-200)/(1.12)^1 + 300/(1.12)^2 + 400/(1.12)^3 + 500/(1.12)^4 + 500/(1.12)^5 = -800 - 178.57 + 239.16 + 284.71 + 317.76 + 283.71 = 146.77万元。NPV > 0，项目可行。

Extra：<div>理解：第1年仍为负现金流，也要折现。注意前两年现金流为负，累计净现金流到第几年转正。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。多期负现金流代入。

## 某项目各年净现金流：第0年=-1200万，第1年=400万，第2年=400万，第3年=400万，第4年=400万，第5年=400万。计算静态投资回收期。

Back：前3年累计 = -1200+400+400+400 = 0。静态投资回收期 = 3年。

Extra：<div>理解：也可用公式：1200/400=3年（等额回收）。若不等额需要逐年累计。常见错法：忘记第0年投入，把第1年当第0年算。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。经典等额回收计算。

## 某项目各年净现金流：第0年=-1500万，第1年=300万，第2年=500万，第3年=600万，第4年=700万，第5年=500万，折现率10%。计算动态投资回收期。

Back：折现净现金流：第0年=-1500，第1年=272.73，第2年=413.22，第3年=450.79，第4年=478.11，第5年=310.46。累计折现：第0年=-1500，第1年=-1227.27，第2年=-814.05，第3年=-363.26，第4年=114.85。动态回收期 = (4-1) + 363.26/478.11 = 3 + 0.76 = 3.76年。

Extra：<div>理解：先折现再累计。第4年末累计首次≥0，所以T=4。常见错法：没做折现直接用原始现金流算动态回收期。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。计算过程完整。

## A方案NPV=500万，B方案NPV=450万，基准收益率相同，两方案互斥。选择哪个方案？为什么？

Back：选择A方案。NPV越大方案越优，A方案NPV=500万 > B方案NPV=450万。

Extra：<div>理解：互斥方案选优时NPV法优先于IRR法。例：A方案NPV高但IRR低，仍应选A，因为NPV代表绝对收益额。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。方案选择对比。
