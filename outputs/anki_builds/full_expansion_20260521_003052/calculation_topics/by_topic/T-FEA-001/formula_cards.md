## 净现值 NPV 的公式和判断规则是什么？

Back：NPV = Σ(CI - CO)_t × (1 + i)^(-t)。NPV > 0 项目可行；NPV = 0 保本；NPV < 0 不可行。

Extra：<div>理解：CI 现金流入，CO 现金流出，(CI-CO)_t 第 t 年净现金流。i 为折现率。NPV 越大方案越优。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。公式标准，规则明确。

## 静态投资回收期的公式和判断规则是什么？

Back：累计净现金流量首次 ≥ 0 的年份 = (T-1) + |第 T-1 年累计净现金流| / 第 T 年净现金流。T 为累计净现金流首次 ≥ 0 的年份。回收期 ≤ 基准投资回收期时可行。

Extra：<div>理解：不考虑资金时间价值。例：第 2 年末累计 -50，第 3 年净现金流 100，则回收期 = 2 + 50/100 = 2.5 年。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。公式和判断规则完整。

## 动态投资回收期（折现回收期）的公式是什么？

Back：累计折现净现金流量首次 ≥ 0 的年份 = (T-1) + |第 T-1 年累计折现净现金流| / 第 T 年折现净现金流。T 为累计折现净现金流首次 ≥ 0 的年份。

Extra：<div>理解：先把各年净现金流按折现率折现，再用与静态回收期相同的累计方法计算。动态回收期 > 静态回收期，因为折现后后期现金流变小。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。公式清晰。

## 内部收益率 IRR 的概念和判断规则是什么？

Back：IRR 是 NPV = 0 时的折现率。若 IRR ≥ 基准收益率，项目可行；IRR < 基准收益率，项目不可行。

Extra：<div>理解：IRR 是项目本身的收益率，反映资金使用效率。多个方案选优时，NPV 法与 IRR 法可能冲突，应以 NPV 为准。</div><div>来源：T-FEA-001 经济评价专题</div>

Manual review：keep。概念和规则完整。
