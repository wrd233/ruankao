## 某项目各年净现金流如下：第0年=-2000万，第1年=400万，第2年=600万，第3年=800万，第4年=800万，第5年=600万，折现率=10%，基准投资回收期=5年。请计算：（1）NPV；（2）静态投资回收期；（3）动态投资回收期；（4）从NPV和回收期两个角度给出推荐结论。

Back：
（1）NPV = -2000 + 400/1.1 + 600/1.1^2 + 800/1.1^3 + 800/1.1^4 + 600/1.1^5
= -2000 + 363.64 + 495.87 + 601.05 + 546.41 + 372.55 = 379.52万元。NPV>0，项目在经济上可行。

（2）静态回收期：第0年=-2000，第1年=-1600，第2年=-1000，第3年=-200，第4年=600。回收期=3+200/800=3.25年 < 5年，回收期满足。

（3）动态回收期：折现净现金流：第0年=-2000，第1年=363.64，第2年=495.87，第3年=601.05，第4年=546.41，第5年=372.55。
累计折现：第0年=-2000，第1年=-1636.36，第2年=-1140.49，第3年=-539.44，第4年=6.97。
动态回收期=3+539.44/546.41=3+0.987≈3.99年 < 5年，满足。

（4）推荐结论：NPV=379.52万>0，项目财务可行；静态回收期3.25年、动态回收期3.99年均小于基准回收期5年。综合推荐：项目可行，建议采纳。
