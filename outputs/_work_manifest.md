## 输出文件

| 文件名 | 作用 |
|---|---|
| `_work_manifest.md` | 记录当前目录归类、解析能力和交付范围。 |
| `_quality_check.md` | 对本轮深读交付物做结构化自检。 |
| `00_建树前深读交付物总览.md` | 说明本轮目标、材料分层、交付物关系、建树原则与质量标准。 |
| `01_全资料细粒度索引与专题素材映射.md` | 全资料取材地图，按材料分组列出页级/题级/段级索引。 |
| `02_极细粒度专题知识树_叶节点为专题.md` | 全考试知识树；叶节点即后续专题。 |
| `03_专题素材索引库.md` | 以专题为中心聚合来源、讲解主线、图示和题目素材。 |
| `04_真题考法与题目映射索引.md` | 以题目为中心拆出考点、陷阱、专题映射和制卡方向。 |
| `05_全量专题生成清单与依赖路径.md` | 后续逐专题生成学习包时的执行队列和依赖关系。 |
| `extracted_text/_extraction_manifest.json` | 全量文本抽取元数据清单。 |
| `scripts/extract_materials.py` | 本轮统一抽取 PDF/DOC/DOCX/MD 文本的脚本。 |
