> 更新日期：2026-05-20

> 覆盖等级：A = 专题深入覆盖且有例题/案例/辨析；B = 有覆盖但例题或深度不足；C = 只提到，不能单独支撑考试；N = 未覆盖；M = 不适合建专题，转入零散考点题库。

## 覆盖结论总览

- **上午项目管理题覆盖情况：A-/B+。** 过程组、范围、进度、成本、质量、风险、采购、变更、沟通、人力资源等主干题均有正式专题覆盖，本轮又在 31 篇专题中补入真题型训练。
- **上午信息化/技术/标准/法规题覆盖情况：B。** 企业系统、信息化基础、法律采购已覆盖；网络、安全、存储、软件文档、标准代号、资质监理、知识产权等短散题已集中转入 `exam_driven/零散考点与小题型专项训练.md`，但知识产权和资质监理仍建议后续独立建专题。
- **下午案例题覆盖情况：A-。** 2019 下半年下午合同、范围、进度成本、质量四类案例，分别由采购合同、范围变更、进度成本、质量案例模板覆盖；案例通用审题法提供横向框架。
- **计算题覆盖情况：A-。** 挣值管理、关键路径、PERT/进度网络、沟通渠道、EMV 均有专题覆盖；经济评价和加权评分属于弱覆盖或零散题。
- **零散考点覆盖情况：B。** 本轮新增专项训练文件，覆盖标准代号、软件文档、软件质量、信息化体系、电子商务、网络安全、存储、招投标、资质监理、知识产权、英文术语和加权评分。
