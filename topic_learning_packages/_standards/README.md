# 专题学习包建设标准

本目录保存正式专题学习包建设标准。

## 文件说明

- `04_专题学习包_新版样例_v2_T007_PERT估算与进度压缩.md` — **T007 正式专题正文样例**。所有专题学习包应以本文的深度、结构和文风为标准。
- `软考专题学习包建设说明_v2_以T007样例为标准.md` — **全项目专题建设规范**。定义了专题如何建设、如何验收、如何组织文件结构。

## 重要区分

- `outputs/00-05` 文件和 `samples/00-05` 文件是索引层、素材层、规划层的样例，不是正式专题正文样例。
- 本阶段的主交付必须模仿 T007 样例，而不是继续扩写 00-05 风格的索引文件。
