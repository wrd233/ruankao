# 专题全量升级报告

> 更新日期：2026-05-20  
> 范围：`topic_learning_packages/topics/**/*.md` 31 篇正式专题。

## 一、本轮改动范围

本轮不是新增大批专题，而是对现有 31 篇正式专题做全量质量升级：保留原有主线和讲义内容，在每篇专题中增补真题覆盖增强段，使专题更接近 T007 的“主线清楚、图示支撑、例题完整、可制卡”的标准。

同时新增两类关键辅助产物：

- `index/exam_question_coverage_matrix.md`：从历年试题视角反查专题覆盖。
- `exam_driven/零散考点与小题型专项训练.md`：把短散但会考的小题集中组织。

## 二、T007 标准靠近方式

本轮没有机械复制 T007 标题，而是学习它的功能结构：

- 每篇专题都用真题题干信号把概念拉回考试语境。
- 每篇专题新增 Mermaid 题型信号图，强化“题干 → 考点 → 排错 → 制卡”的链路。
- 新增训练题均包含考查点、题干关键词、解题过程、正确答案、错项分析、举一反三和可制卡点。
- 对不确定法规、标准、资质和术语继续保留 `[待核验]`，并集中进入总账。
